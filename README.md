# Nail Rescue: Nail Salon Makeover

Rescue chipped, stained nails in a cosy salon: clean, push back cuticles, glue on tips, file the shape, paint, add nail art, charms and jewelry, then enjoy the glam ta-da reveal.

**Play:** https://lrodeveloperr.github.io/nail-rescue/

![Nail Rescue](cover.png)

This is the web build for testing in any browser. It runs with a local stand-in for the YouTube Playables SDK, so ads are simulated. The release build for YouTube Playables is submitted through MediaCube's McPlay.

Built with PixiJS. Art is original (drawn in code) or CC0; music is generated in code; sounds are CC0 (Freesound, Kenney).
